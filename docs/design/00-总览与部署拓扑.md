## 部署基线（用户已定，全部设计文档共同遵守）

```
┌── 本机（GPU，NAT 后，无公网 IP，零入站端口）──────────────┐
│ 模拟内核（Python asyncio 单进程，tick 串行裁决）            │
│ LLM 网关（路由/降级链/全量记录/¥每模拟日计量）              │
│ 本地模型（vLLM）：Qwen3-4B/8B 安全初筛 · bge-m3 embedding  │
│                  · 本地 8B 次要层兜底（sleep-mode 按需）    │
│ PostgreSQL 16 + pgvector 主库（append-only 事件表）        │
└──────────────┬───────────────────────────────────────────┘
               │ 出站 WSS 长连（事件批量推送，ACK+断点续传，
               │ 断网本地照跑、恢复后 500 条/批流水追平）
┌──────────────▼───────────────────────────────────────────┐
│ 云端（公网 IP）                                            │
│ 摄入 API（幂等：events.seq 唯一索引，digest 每日校验）      │
│ 事件副本 PostgreSQL（只读投影，物理删除 text_raw 列）       │
│ Web 观察端（nginx 静态托管 + WS 反代，开发期 token 访问）   │
│ 切片素材与发布管线                                          │
└───────────────────────────────────────────────────────────┘
```

- 本机不出任何入站端口；云端 LLM API key 只存本机，云端失陷不波及 LLM 账单。
- 双通道分离在管道级实现：观察端展示文本与内部记忆物理隔离（副本库无 `text_raw` 列）。
- 可回放 = 重放事件流（replay），不是重算世界；业务排序/续传/cursor 一律以单调 `seq` 为准，`tick`/`sim_time` 仅裁决节拍与展示。

## 命名约定（定死）

- **对外产品名：WorldSim**；CitySim 仅为仓库名，不得出现在对外文案、UI、服务/包名中（评审 P2-14）。
- agent 标识统一为字符串 `'A01'~'A40'`（DB TEXT / YAML / 协议 / UI 全场景同形）；事件与字段命名详见 [06-契约登记表.md](06-契约登记表.md)。

## 跨文档衔接点

- **UI 视觉 token**（色值/字号/间距）唯一定义在 02-美术 §7，03-客户端引用，不另起炉灶。
- **涟漪追踪的数据依赖**（记忆 `source_event_seq/is_witness`、gossip `payload.cites`、事件 `payload.caused_by`）由 03 提出：主库侧 04 落库、副本库侧由 **05 物化层承接**（`memory_projection/relation_change_log/ripple_edge` 等），不触碰事件 Schema v1 顶层；字段唯一名见 06 §2。
- **digest 一致性校验以"同步规范形"计算**：双方按同一白名单剥除 `text_raw` 后的 canonical payload 做 hash，或仅覆盖 `COUNT/SUM(seq)` 等不依赖 payload 的量——副本库物理剥除 `text_raw` 与 digest 不再互斥（评审 P1-3，列入 W1 演练必过项）。
- **对话逐句播放**：独立 `presentation_queue` 通路取消；逐句时间表并入 `events.payload.lines[].at_offset_s`，播放节拍以客户端倍率为唯一权威（评审 P2-7）。
- **门禁③阈值**在 W0 市场调研后写死（源方案 §8.1），02 美术不预设数值。
- **GPU 预算表**为 W1 实测填写的空模板（04 §1）；**¥/模拟日止损上限**待 W2 初测后写死。
- 美术三阶段预算合计 ≤¥3,100，计入源方案 ¥8,000 项目止损线。

## 1. 范围

- `stream/` 独立零依赖静态页（00 §1 A7、00 §3"直播页"行）：原生 HTML/CSS/JS，无构建步骤、无 npm 依赖，WS 直连观察端 API（03 §5.2），token 鉴权（03 §8.3）。
- normal / climax 两形态按事件流自动切换（触发集复用 02 §7.6 注册条件；回落计时器为工程默认值，已登记）。
- 字幕引擎：对话类事件整段接收、逐句节拍播放（`payload.lines[].at_offset_s` ÷ 客户端倍率，06 §2 / 04 §6.4），字幕条避开底部 220px 平台安全区（02 §6.2）。
- 人物特写浮层：dialogue 事件弹出说话人写实特写（`ui/assets/portraits/`，02 §1.1.2），位置/尺寸不遮挡字幕与安全区，超时收起。
- 飘屏占位组件（"互动只影响下一段"口径，04 §6.4）。
- 头像/特写静态资源路由（开发期 FastAPI obs-api 挂载；生产 nginx 直托片段入 `deploy/`）。
- 签名色池/视觉 token 静态化与校验脚本（02 §4.3/§7.1/§8.3）；缺特写人物兜底（签名色 + 姓名首字，与 web-lite 原型 `.av` 一致）。

## 4. 契约红线自查（00 §4 中本模块强相关条目）

1. agent id 一律 `'A01'~'A40'` TEXT 形态（红线 1）——manifest key、roster 解析、特写/字幕人名查找全链路同形。
2. 事件排序/续传只用单调 `seq`（红线 2）；`payload.caused_by` / `changes[].cause` / `target_seq` 为裸 seq 数字字符串（红线 3）——climax 触发⑤与 grade 改判匹配按此形态比较，禁止 `'e<seq>'` 作值。
3. 画面文字全部来自 `text_display` / `lines[].text_display`；`text_raw` 永不接触页面（红线 7；05 §2.1 白名单已保证不出站，页面侧再断言一次）。
4. `visibility='internal'` 事件（`state.needs_delta`/`relation.changed`/`time.*`/`system.llm.*`）结构化 payload 照常出站（06 §1.2 表头）：页面只消费不渲染（`relation.changed` 用于触发⑤、`time.day_summary` 用于 Day 标签），非调试态零展示。
5. 逐句时间表只有 `lines[].at_offset_s` 一个权威，客户端倍率是播放唯一权威（红线 9、04 §6.4）——直播页无播放控件，倍率取值见 §7 偏差 B3。
6. 事件类型只允许 06 §1.2 注册表内的名字（红线 5）——字幕/特写/触发判定用到的类型清单见各任务实现要点，新增需求先回登 06（§4 流程）。

### T-ART-01 签名色池与视觉 token 静态化
- 里程碑 / 依赖: M5 ；无（仅设计文档）
- 设计依据: 02 §4.3（16 色池与 ΔE 校验约束）、02 §7.1（六语义色 + 分工立法）、02 §8.3（`palette/worldsim.gpl` 落点）、02 §2.3（场景变体色）
- 目标: 签名色/语义色/场景色三表以机器可读形态入库，ΔE 全对校验与 stream 页取色合法性检查脚本化。
- 交付物: `ui/assets/palette/worldsim.gpl`；`ui/assets/palette/allowed_hex.txt`（三表 HEX 并集，逐行注释来源节号）；`server/scripts/check_delta_e.py`（纯 stdlib 实现 CIEDE2000）；`server/scripts/check_stream_hex.py`；`stream/css/tokens.css`（`:root` 变量 = 02 §7.1 token HEX 原值）。
- 实现要点:
  - `worldsim.gpl` 收录 02 §4.3 全部 16 签名色（色名逐字：朱红/钴蓝/翠绿/琥珀/青碧/暗红/堇紫/天青/杏黄/鼠尾草绿/紫藤/蔷薇/咖啡/雾蓝/芥末/岩灰）+ 02 §7.1 六语义色（`positive/negative/warn/neutral/director/accent` 及 bg/text/border 各 token）。
  - ΔE 校验口径照 02 §4.3 约束 2：池内 C(16,2)=120 对全对 ΔE(CIEDE2000) ≥15；16 色 × 6 语义色 96 对全对 ≥15。
  - `tokens.css` 只含 02 §7.1 定义值；stream 页一切 HEX 必须落在 `allowed_hex.txt`（02 §2.3 ∪ §4.3 ∪ §7.1）内，舞台 SVG 场景色取 02 §2.3 夜晚变体。
  - palette/ 数据落点为 `ui/assets/`（仓内实际资产根，00 §2），与 02 §8.3 树形差异见 §7 偏差 B2。
  - 两个校验脚本按 00 §1 A14 统一落 `server/scripts/`（数据文件仍在 `ui/assets/palette/`，脚本内以仓根相对路径解析）。
- 验收标准:
  1. `cd server && uv run python scripts/check_delta_e.py` 退出码 0（00 §1 A14 调用约定），输出池内 120 对与语义色 96 对的最小 ΔE 值。
  2. `cd server && uv run python scripts/check_stream_hex.py` 退出码 0：`grep -ohE '#[0-9A-Fa-f]{6}' stream/ -r | sort -u` 全集 ⊆ `allowed_hex.txt`。
  3. `worldsim.gpl` 条目色名与 02 §4.3/§7.1 逐字一致（脚本断言，含"雾蓝"唯一指向 #14 校验）。
- 实测回填: 若 ΔE 实测最小值与 02 §4.3 记录值（池内 15.5 / 语义色 15.3）不符，回改 02 §4.3。

### T-LTV-02 WS 客户端（零依赖原生 WebSocket）
- 里程碑 / 依赖: M5 ；M4 obs-api WS（05-Web 文档）；T-ART-03（页面经 obs-api 托管）
- 设计依据: 03 §5.2（hello/subscribe/welcome/event/resume/resync_required/心跳/退避全帧型）、03 §8.3（token：`?token=` 或 Bearer、hello 帧携带）、03 §9.1（断线重连验收口径）

- 验收标准:
  1. `node --test stream/tests/ws-client.test.js` 全绿：hello→subscribe 帧序列断言；`last_seq` resume 帧断言；退避序列落在 [0.8×,1.2×]·(1,2,4,8,16,30,30…) 区间；90s 无 pong 触发重连；`resync_required` 触发 snapshot 回调；重复 seq 事件被去重。

## 4. 任务表

### T-ENV-01 PostgreSQL 16 无 root 源码编译（pg_build.sh）
- 里程碑 / 依赖: M0 ；无
- 设计依据: 00 §1 A1、00 §3（DB 钉版 PG 16.x 源码编译）、04 §5（PG16+pgvector 0.8 硬要求）
- 目标: 一个幂等脚本把 PostgreSQL 16 从官方 tarball 编译装入 `~/pgsql`，全程不需要 root/docker。
- 交付物: `server/scripts/pg_build.sh`
- 实现要点:
  - 脚本顶部钉版本变量 `PG_VERSION=16.<minor>`（开工当日取最新 16.x stable  tarball，回填本文 §5 R6）；`PREFIX=$HOME/pgsql`，build 目录 `~/pgsql/build`。
  - 下载 `postgresql-${PG_VERSION}.tar.bz2`（发布 tarball 自带预生成 gram/scan，**无需 bison/flex**）；`./configure --prefix="$PREFIX" --without-readline`（zlib 用系统已有，configure 默认探测）。
  - `make -j"$(nproc)" && make install`；含 `contrib/` 不装。幂等：`$PREFIX/bin/postgres --version` 命中目标版本则跳过。
  - 校验环境前置：无 root 依赖路径写入、无 sudo 调用。
- 验收标准:
  1. `bash server/scripts/pg_build.sh` 全新跑通，退出码 0；重复执行第二次输出 "already installed" 且退出码 0。
  2. `~/pgsql/bin/postgres --version` 输出匹配 `^postgres \(PostgreSQL\) 16\.`。
  3. `ldd ~/pgsql/bin/postgres | grep -i readline` 无输出（`--without-readline` 生效）；`ldd ~/pgsql/bin/postgres | grep 'libz\.so'` 有输出（系统 zlib 链接）。
  4. 构建日志 `grep -iE 'bison|flex' ~/pgsql/build/*.log` 无实际调用行（证明 tarball 预生成文件够用）。
- 实测回填: PG minor 版本号 → 本文 §5 R6。

### T-ENV-03 实例初始化与角色创建（db_init.sh）
- 里程碑 / 依赖: M0 ；T-ENV-02
- 设计依据: 00 §1 A1（数据目录 `~/pgsql/data`，unix socket + 127.0.0.1:5432）、05 §5（只读账号 `obs_ro`）
- 目标: 幂等脚本完成 initdb、启停、建库、建角色，产出开发期可用的主库实例。
- 交付物: `server/scripts/db_init.sh`
- 实现要点:
  - `initdb -D ~/pgsql/data`（locale `C.UTF-8`）；`postgresql.conf` 仅改 `port=5432`、`listen_addresses='127.0.0.1'`、`timezone='Asia/Shanghai'`（见 §6 D4）。
  - 子命令：`init / start / stop / status / reset`（`reset` = drop+create database `worldsim`，供测试反复跑 DDL）。
  - 建库 `worldsim`（库名见 §6 D2）；库内 `CREATE EXTENSION vector; CREATE EXTENSION pg_partman;`。
  - 角色：`worldsim`（LOGIN，应用角色，密码从 `.env` 的 `WSIM_PG_DSN` 解析，不入 git）与 `obs_ro`（LOGIN，只读占位，授权在 T-DB-03）；认证 unix socket trust + 127.0.0.1 scram-sha-256（见 §6 D2）。
- 验收标准:
  1. `server/scripts/db_init.sh init && server/scripts/db_init.sh start` 后 `pg_isready -h 127.0.0.1 -p 5432` 返回 accepting。
  2. `psql "postgresql://worldsim@127.0.0.1:5432/worldsim" -c 'SELECT 1'` 连通（走 TCP）；`psql -h /tmp -d worldsim -c 'SELECT 1'` 或默认 socket 目录连通（unix socket，A1 双通道）。
  3. `psql -c '\du'` 含 `worldsim` 与 `obs_ro` 两角色；`\l` 含 `worldsim` 库。
  4. `db_init.sh reset` 后库内无用户表；脚本整体重复执行幂等（已 init 则跳过并提示）。
- 实测回填: 无。

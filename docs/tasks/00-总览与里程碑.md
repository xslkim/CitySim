## 4. 契约红线（写代码前自查清单，源自 06，违例即返工）

1. agent id 一律 TEXT `'A01'~'A40'`，任何表/协议/YAML/UI 不得出现 INT 或 `ag07` 形态。
2. 事件排序/续传/cursor 只用单调 `seq`；`'e<seq>'` 仅是 UI/日志展示形态，**禁止作值**。
3. `payload.caused_by` / `cites[]` / `changes[].cause` / `for_event_ref` / `target_seq` / `request_ref` = **裸 seq 数字字符串**（`'1089'`）。
4. `events` 表 append-only：REVOKE UPDATE/DELETE + 触发器；grade 改判只追加 `director.grade_revise`。
5. 事件类型/字段只允许 06 §1.2 注册表内的名字；新类型先登记 06 再实现。
6. 金额统一 `payload.amount_cents`（分，正入负出）；economy 审计类型清单由 06 §1.2 标记生成，不用 `LIKE` 对账。
7. `text_raw` 永不出站；`text_display` 仅 `visibility='public'` 事件放行；未登记键默认剥除。
8. `fidelity`（内核传播输入）与 `distortion`（云端 ripple_edge 展示度量）分立，不混用、不进 payload。
9. 对话整段落库，逐句时间表 `payload.lines[].at_offset_s`，客户端倍率是播放唯一权威（相邻句间隔 ÷ 倍率）。
10. tick = 模拟 5 分钟；**只有一个裁决协程写状态**；LLM 并发、落库串行。
11. 压缩比只调观看节奏，不改世界密度：认知排程只读 sim_time。
12. 双通道：观察端一切数据来自白名单（视图/副本库），内部记忆与展示文本物理隔离。
13. 干预审计只看 `trigger` 字段；`director` 发起的 world.* 事件计入干预率（红线见源方案 §4.8）。
14. 触发器枚举封闭：`autonomous | world | director | gift | vote | system`（gift/vote 阶段 1 不用）。

## 8. 最终冒烟（交付验收，`server/scripts/smoke.sh` 一条命令，T-OPS-05 创建）

全链路冷启动冒烟，对应项目完成定义：

1. 冷启动序列：`db_init.sh` → `schema_v1.sql` → `seed_8.sql` →（M6 后含 `replica_init.sh`）→ `start_local.sh` 起全栈（PG + 内核 + obs_refresh 常驻 + 摄入 API + 观察端 API + web dev server）
2. 内核运行 ≥10 真实分钟（加速档；冒烟工程口径）：断言 `events` 持续增长、`seq` 无空洞单调递增、事件类型覆盖 ≥6 类（冒烟工程口径）
3. `WSIM_REPLAY_MODE=replay` 对刚跑过的时段重放：零 LLM 调用、状态对账一致
4. 观察端 API：先经 05 T-WEB-02 的 tokens_cli 签发 dev token；`curl` 快照/事件/角色三端点 200；响应体经 `pnpm proto:check`（`web/scripts/proto_check.mjs`，zod 校验，T-WEB-09 交付）通过；WS 连接收增量事件
5. headless chromium（`/home/xsl/.local/bin/chromium`）截图三页，URL 写死：admin `http://127.0.0.1:5173/map`、lite `http://127.0.0.1:5173/lite/home`（web dev server 端口 5173，T-WEB-08 钉版）、stream `http://127.0.0.1:8080/stream/?token=<dev token>`（obs-api 托管，T-ART-03）；非白屏且含事件文本与头像
6. 审计 `audit_run.py` 全绿；`llm_calls` 有行且 ¥ 聚合 >0（M2 后）
7. 产出 `var/logs/smoke_report.txt`（各项 PASS/FAIL + 关键计数）；全 PASS 才算交付
